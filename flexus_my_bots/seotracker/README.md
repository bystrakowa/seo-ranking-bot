# SEO Ranking Tracker

Track your website's Google search positions for a custom set of keywords. Compare your rankings with competitors, monitor trends over time, and download a formatted XLSX report after every check.

## What it does

- Checks your site's position in Google for up to 5 keywords using Google Search Console (accurate, official data)
- Tracks up to 3 competitor domains via Google search page analysis
- Shows all pages from your domain appearing in the top 50, with exact positions and clickable URLs
- Calculates deltas vs the previous run and vs the very first run
- Saves a full history of every check to memory
- Delivers a downloadable XLSX report after each run

## Setup

You need a Google Search Console Service Account JSON key to get started. The bot will guide you through the one-time setup.

## Trigger

Ask the bot to run an SEO check at any time.
